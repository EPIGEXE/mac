# 트리와 그래프

## 그래프 (Graph)

**정점(Vertex)과 간선(Edge)으로 이루어진 자료구조**입니다. 객체 간의 관계를 표현합니다.

```
정점(노드): V = {A, B, C, D, E}
간선: E = {(A,B), (A,C), (B,D), (C,D), (D,E)}

    A ─── B
    │     │
    C ─── D ─── E
```

**그래프 종류:**

| 종류 | 설명 |
|------|------|
| **무방향 그래프** | 간선에 방향 없음 (A-B는 양방향) |
| **방향 그래프** | 간선에 방향 있음 (A→B는 단방향) |
| **가중치 그래프** | 간선에 비용/거리 값 |
| **연결 그래프** | 모든 정점이 연결됨 |
| **비연결 그래프** | 분리된 컴포넌트 존재 |
| **순환 그래프** | 사이클 존재 |
| **비순환 그래프** | 사이클 없음 (DAG) |

**그래프 표현 방법:**

```
인접 행렬 (Adjacency Matrix):
    A  B  C  D
A [ 0  1  1  0 ]
B [ 1  0  0  1 ]
C [ 1  0  0  1 ]
D [ 0  1  1  0 ]

공간: O(V²)
간선 확인: O(1)
모든 인접 정점: O(V)

인접 리스트 (Adjacency List):
A → [B, C]
B → [A, D]
C → [A, D]
D → [B, C]

공간: O(V + E)
간선 확인: O(degree)
모든 인접 정점: O(degree)
```

희소 그래프(간선 적음)는 인접 리스트, 밀집 그래프(간선 많음)는 인접 행렬이 효율적입니다.

## 트리 (Tree)

**사이클이 없는 연결 그래프**입니다. 계층적 구조를 표현합니다.

```
        A (루트)
       /|\
      B C D
     /|   |
    E F   G
   /
  H (리프)
```

**트리 용어:**

| 용어 | 설명 |
|------|------|
| **루트 (Root)** | 최상위 노드 (부모 없음) |
| **리프 (Leaf)** | 자식이 없는 노드 |
| **부모/자식** | 직접 연결된 상위/하위 노드 |
| **형제 (Sibling)** | 같은 부모를 가진 노드 |
| **깊이 (Depth)** | 루트에서 해당 노드까지 거리 |
| **높이 (Height)** | 해당 노드에서 가장 먼 리프까지 거리 |
| **차수 (Degree)** | 자식 노드 수 |
| **서브트리** | 특정 노드를 루트로 하는 트리 |

**트리 속성:**
- 노드가 N개면 간선은 N-1개
- 임의의 두 노드 사이에 경로가 유일함
- 루트에서 모든 노드로 가는 경로 존재

---

## 트리 vs 그래프

| 구분 | 트리 | 그래프 |
|------|------|--------|
| **사이클** | 없음 | 있을 수 있음 |
| **방향** | 루트→리프 (암묵적) | 방향/무방향 |
| **루트** | 하나 존재 | 없음 |
| **부모-자식** | 명확함 | 없음 |
| **연결성** | 항상 연결 | 비연결 가능 |
| **간선 수** | N-1 (N은 노드 수) | 자유로움 |
| **경로** | 유일함 | 여러 개 가능 |
| **계층** | 있음 | 없음 |

```
트리 (Tree):          그래프 (Graph):
    A                     A ─── B
   / \                    │ \   │
  B   C                   │  \  │
 / \                      C ─── D
D   E                     (사이클 존재)
```

**트리는 그래프의 특수한 경우**입니다. 모든 트리는 그래프지만, 모든 그래프가 트리는 아닙니다.

## 이진 트리 (Binary Tree)

**각 노드가 최대 2개의 자식(왼쪽, 오른쪽)을 가지는 트리**입니다.

```
      A
     / \
    B   C
   / \   \
  D   E   F
```

**이진 트리 종류:**

| 종류 | 설명 |
|------|------|
| **정 이진 트리 (Full)** | 모든 노드가 0개 또는 2개 자식 |
| **완전 이진 트리 (Complete)** | 마지막 레벨 제외 모두 채워짐, 왼쪽부터 채움 |
| **포화 이진 트리 (Perfect)** | 모든 레벨이 완전히 채워짐 |
| **균형 이진 트리 (Balanced)** | 좌우 서브트리 높이 차이 ≤ 1 |
| **편향 이진 트리 (Skewed)** | 한쪽으로만 자식 존재 |

```
정 이진 트리:     완전 이진 트리:    포화 이진 트리:
      A               A                  A
     / \             / \                / \
    B   C           B   C              B   C
   / \             / \  /             / \ / \
  D   E           D  E F             D  E F  G
```

## 이진 탐색 트리 (BST, Binary Search Tree)

**왼쪽 서브트리 < 노드 < 오른쪽 서브트리** 속성을 만족하는 이진 트리입니다.

```
        8
       / \
      3   10
     / \    \
    1   6    14
       / \   /
      4   7 13

왼쪽 서브트리의 모든 값 < 부모 < 오른쪽 서브트리의 모든 값
```

**BST 연산:**

```c
// 검색: O(h), h는 트리 높이
Node* search(Node* root, int key) {
    if (root == NULL || root->data == key)
        return root;
    
    if (key < root->data)
        return search(root->left, key);
    else
        return search(root->right, key);
}

// 삽입: O(h)
Node* insert(Node* root, int key) {
    if (root == NULL)
        return createNode(key);
    
    if (key < root->data)
        root->left = insert(root->left, key);
    else if (key > root->data)
        root->right = insert(root->right, key);
    
    return root;
}
```

**삭제 연산:**

```
Case 1: 리프 노드 → 그냥 삭제

Case 2: 자식 1개 → 자식을 부모와 연결
        8                8
       / \              / \
      3   10    →      3   14
           \              /
           14           13
           /
         13

Case 3: 자식 2개 → 중위 후속자(또는 전임자)로 대체
        8                9
       / \              / \
      3   10    →      3   10
     / \    \         / \    \
    1   6   14       1   6   14
       / \  /           / \  /
      4  7 9           4  7 13
          ↑
    8의 중위 후속자 (오른쪽 서브트리의 최소값)
```

**시간복잡도:**

| 연산 | 평균 | 최악 (편향) |
|------|------|------------|
| 검색 | O(log n) | O(n) |
| 삽입 | O(log n) | O(n) |
| 삭제 | O(log n) | O(n) |

최악의 경우는 트리가 한쪽으로 편향되어 연결 리스트처럼 될 때입니다.

```
편향 BST (정렬된 순서로 삽입 시):
1
 \
  2
   \
    3
     \
      4   → 높이 = n, 검색 O(n)
```

## 트리 순회 (Tree Traversal)

**전위 순회 (Preorder): 루트 → 왼쪽 → 오른쪽**

```c
void preorder(Node* root) {
    if (root == NULL) return;
    printf("%d ", root->data);  // 루트 먼저
    preorder(root->left);
    preorder(root->right);
}

// 활용: 트리 복사, 전위 표기법
```

**중위 순회 (Inorder): 왼쪽 → 루트 → 오른쪽**

```c
void inorder(Node* root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%d ", root->data);  // 루트 중간
    inorder(root->right);
}

// BST에서 정렬된 순서 출력!
```

**후위 순회 (Postorder): 왼쪽 → 오른쪽 → 루트**

```c
void postorder(Node* root) {
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%d ", root->data);  // 루트 마지막
}

// 활용: 트리 삭제, 후위 표기법 계산
```

**레벨 순회 (Level Order): BFS**

```
큐를 사용하여 레벨별로 방문

      8
     / \
    3   10
   / \
  1   6

출력: 8 3 10 1 6
```

**순회 예시:**

```
        8
       / \
      3   10
     / \
    1   6

전위: 8 3 1 6 10
중위: 1 3 6 8 10 (정렬!)
후위: 1 6 3 10 8
레벨: 8 3 10 1 6
```

## 균형 이진 탐색 트리

BST의 편향 문제를 해결하여 **O(log n)을 보장**합니다.

**AVL 트리:**
- 모든 노드에서 좌우 서브트리 높이 차이 ≤ 1
- 삽입/삭제 시 회전으로 균형 유지
- 엄격한 균형 → 검색 빠름, 삽입/삭제 느림

**Red-Black 트리:**
- 노드에 색상(Red/Black) 부여
- 규칙: 루트는 Black, Red 연속 불가, Black 높이 동일
- AVL보다 덜 엄격 → 삽입/삭제 빠름
- Java TreeMap, C++ std::map에서 사용

| 구분 | AVL | Red-Black |
|------|-----|-----------|
| 균형 조건 | 높이 차이 ≤ 1 | 색상 규칙 |
| 검색 | 더 빠름 | 약간 느림 |
| 삽입/삭제 | 느림 (회전 많음) | 빠름 |
| 활용 | 검색 위주 | 삽입/삭제 빈번 |

## 트리 활용

| 트리 종류 | 활용 |
|----------|------|
| **이진 탐색 트리** | 검색, 정렬된 데이터 관리 |
| **힙** | 우선순위 큐, 힙 정렬 |
| **트라이 (Trie)** | 문자열 검색, 자동완성 |
| **B-트리** | 데이터베이스 인덱스, 파일 시스템 |
| **세그먼트 트리** | 구간 쿼리 |
| **표현식 트리** | 수식 파싱, 계산 |

## 그래프 탐색

**DFS (깊이 우선 탐색):**

```
스택 또는 재귀 사용
한 경로를 끝까지 탐색 후 백트래킹

활용: 경로 찾기, 사이클 탐지, 위상 정렬, 연결 요소
```

**BFS (너비 우선 탐색):**

```
큐 사용
가까운 노드부터 탐색

활용: 최단 경로 (가중치 없는 그래프), 레벨별 탐색
```

```
    A
   /|\
  B C D
  |   |
  E   F

DFS (A 시작): A → B → E → C → D → F
BFS (A 시작): A → B → C → D → E → F
```

## 면접 예상 질문

**Q. 트리와 그래프의 차이?**

트리는 사이클이 없는 연결 그래프로 계층 구조를 표현합니다. 루트가 있고, 노드 N개면 간선 N-1개, 두 노드 간 경로가 유일합니다. 그래프는 사이클이 있을 수 있고, 루트 개념이 없으며, 경로가 여러 개일 수 있습니다.

**Q. BST의 특징과 시간복잡도?**

왼쪽 서브트리 < 노드 < 오른쪽 서브트리 속성을 만족합니다. 평균 O(log n)으로 검색, 삽입, 삭제가 가능합니다. 중위 순회하면 정렬된 순서가 됩니다. 최악의 경우(편향) O(n)이 되어 균형 트리로 해결합니다.

**Q. BST가 O(n)이 되는 경우?**

정렬된 순서로 삽입하면 한쪽으로만 자식이 연결되어 연결 리스트처럼 됩니다. 높이가 n이 되어 모든 연산이 O(n)입니다. AVL이나 Red-Black 트리로 균형을 유지하면 O(log n)을 보장합니다.

**Q. 트리 순회 방식?**

전위(루트→왼쪽→오른쪽), 중위(왼쪽→루트→오른쪽), 후위(왼쪽→오른쪽→루트), 레벨(BFS) 순회가 있습니다. BST의 중위 순회는 정렬된 결과를 출력합니다. 트리 삭제는 후위 순회로 자식부터 삭제합니다.

**Q. AVL과 Red-Black 트리 차이?**

AVL은 좌우 높이 차이 1 이하로 엄격하여 검색이 빠르지만 회전이 많습니다. Red-Black은 색상 규칙으로 덜 엄격하여 삽입/삭제가 빠릅니다. 검색 위주면 AVL, 삽입/삭제 빈번하면 Red-Black이 적합합니다.

**Q. 그래프 표현 방법?**

인접 행렬은 O(V²) 공간, O(1) 간선 확인으로 밀집 그래프에 적합합니다. 인접 리스트는 O(V+E) 공간으로 희소 그래프에 적합합니다. 대부분의 실제 그래프는 희소하여 인접 리스트를 많이 사용합니다.
