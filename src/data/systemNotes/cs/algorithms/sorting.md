# 정렬 알고리즘

## 정렬 알고리즘 개요

**데이터를 특정 기준에 따라 순서대로 나열**하는 알고리즘입니다.

**평가 기준:**
- **시간 복잡도**: 최선/평균/최악
- **공간 복잡도**: 추가 메모리 사용량
- **안정성 (Stability)**: 같은 값의 상대적 순서 유지 여부
- **제자리 (In-place)**: 추가 공간 O(1) 또는 O(log n) 사용

```
안정 정렬 예시:
원본: [(A,3), (B,1), (C,3), (D,2)]
키로 정렬 시:

안정:   [(B,1), (D,2), (A,3), (C,3)]  ← A가 C보다 앞 (원본 순서 유지)
불안정: [(B,1), (D,2), (C,3), (A,3)]  ← 순서 바뀔 수 있음
```

## O(n²) 정렬 알고리즘

### 버블 정렬 (Bubble Sort)

**인접한 두 요소를 비교하여 교환**하며, 큰 값이 거품처럼 뒤로 이동합니다.

```
[5, 3, 8, 4, 2]
 ↓
[3, 5, 4, 2, 8]  ← 8이 맨 뒤로
 ↓
[3, 4, 2, 5, 8]  ← 5가 제자리로
 ↓
[3, 2, 4, 5, 8]
 ↓
[2, 3, 4, 5, 8]
```

```c
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(&arr[j], &arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;  // 이미 정렬됨
    }
}
```

| 최선 | 평균 | 최악 | 공간 | 안정성 |
|------|------|------|------|--------|
| O(n) | O(n²) | O(n²) | O(1) | 안정 |

### 선택 정렬 (Selection Sort)

**최솟값을 찾아 맨 앞과 교환**을 반복합니다.

```
[5, 3, 8, 4, 2]
 ↓ 최소 2 선택
[2, 3, 8, 4, 5]  ← 2와 5 교환
 ↓ 최소 3 선택 (이미 제자리)
[2, 3, 8, 4, 5]
 ↓ 최소 4 선택
[2, 3, 4, 8, 5]
 ↓
[2, 3, 4, 5, 8]
```

```c
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }
        swap(&arr[i], &arr[minIdx]);
    }
}
```

| 최선 | 평균 | 최악 | 공간 | 안정성 |
|------|------|------|------|--------|
| O(n²) | O(n²) | O(n²) | O(1) | 불안정 |

### 삽입 정렬 (Insertion Sort)

**현재 요소를 정렬된 부분의 올바른 위치에 삽입**합니다.

```
[5, 3, 8, 4, 2]
[5 | 3, 8, 4, 2]  ← 5는 정렬됨
[3, 5 | 8, 4, 2]  ← 3을 앞에 삽입
[3, 5, 8 | 4, 2]  ← 8은 제자리
[3, 4, 5, 8 | 2]  ← 4를 올바른 위치에 삽입
[2, 3, 4, 5, 8]   ← 2를 맨 앞에 삽입
```

```c
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

| 최선 | 평균 | 최악 | 공간 | 안정성 |
|------|------|------|------|--------|
| O(n) | O(n²) | O(n²) | O(1) | 안정 |

**특징:** 거의 정렬된 데이터에 매우 효율적, 소규모 데이터에 적합

## O(n log n) 정렬 알고리즘

### 병합 정렬 (Merge Sort)

**분할 정복**: 배열을 반으로 나누고, 각각 정렬 후 병합합니다.

```
[5, 3, 8, 4, 2, 7, 1, 6]
        분할
[5, 3, 8, 4] [2, 7, 1, 6]
    분할          분할
[5, 3] [8, 4] [2, 7] [1, 6]
  분할   분할   분할   분할
[5][3] [8][4] [2][7] [1][6]
  병합   병합   병합   병합
[3, 5] [4, 8] [2, 7] [1, 6]
    병합          병합
[3, 4, 5, 8] [1, 2, 6, 7]
        병합
[1, 2, 3, 4, 5, 6, 7, 8]
```

```c
void merge(int arr[], int left, int mid, int right) {
    int n1 = mid - left + 1, n2 = right - mid;
    int L[n1], R[n2];
    
    for (int i = 0; i < n1; i++) L[i] = arr[left + i];
    for (int i = 0; i < n2; i++) R[i] = arr[mid + 1 + i];
    
    int i = 0, j = 0, k = left;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) arr[k++] = L[i++];
        else arr[k++] = R[j++];
    }
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
}
```

| 최선 | 평균 | 최악 | 공간 | 안정성 |
|------|------|------|------|--------|
| O(n log n) | O(n log n) | O(n log n) | O(n) | 안정 |

**특징:** 항상 O(n log n) 보장, 외부 정렬에 적합, 추가 메모리 필요

### 퀵 정렬 (Quick Sort)

**분할 정복**: 피벗을 기준으로 작은 값/큰 값으로 분할 후 재귀 정렬합니다.

```
[5, 3, 8, 4, 2, 7, 1, 6]  피벗: 5
        분할
[3, 4, 2, 1] [5] [8, 7, 6]
    재귀         재귀
[1, 2, 3, 4] [5] [6, 7, 8]
        결합
[1, 2, 3, 4, 5, 6, 7, 8]
```

```c
int partition(int arr[], int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i + 1], &arr[high]);
    return i + 1;
}

void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}
```

| 최선 | 평균 | 최악 | 공간 | 안정성 |
|------|------|------|------|--------|
| O(n log n) | O(n log n) | O(n²) | O(log n) | 불안정 |

**최악의 경우:** 이미 정렬된 배열 + 첫/마지막 요소를 피벗으로 선택

**최적화:**
- 랜덤 피벗 또는 중간값(median-of-three) 선택
- 작은 부분 배열은 삽입 정렬 사용

### 힙 정렬 (Heap Sort)

**최대 힙을 구성하고, 루트(최댓값)를 꺼내어 정렬**합니다.

```
배열 → 최대 힙 구성 → 루트 추출 반복

[5, 3, 8, 4, 2]
     8          최대 힙
    / \
   4   5
  / \
 3   2

[8, 3, 5, 4, 2] → 8을 끝으로 이동 → [2, 3, 5, 4 | 8]
다시 힙 구성 → 반복
```

```c
void heapify(int arr[], int n, int i) {
    int largest = i;
    int left = 2 * i + 1, right = 2 * i + 2;
    
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    
    if (largest != i) {
        swap(&arr[i], &arr[largest]);
        heapify(arr, n, largest);
    }
}

void heapSort(int arr[], int n) {
    // 최대 힙 구성
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);
    
    // 루트 추출 반복
    for (int i = n - 1; i > 0; i--) {
        swap(&arr[0], &arr[i]);
        heapify(arr, i, 0);
    }
}
```

| 최선 | 평균 | 최악 | 공간 | 안정성 |
|------|------|------|------|--------|
| O(n log n) | O(n log n) | O(n log n) | O(1) | 불안정 |

**특징:** 항상 O(n log n) 보장, 제자리 정렬, 캐시 효율 낮음

## O(n) 정렬 알고리즘 (비교 기반 X)

### 계수 정렬 (Counting Sort)

**각 값의 개수를 세어 정렬**합니다. 정수 범위가 제한적일 때 사용합니다.

```
[4, 2, 2, 8, 3, 3, 1]  범위: 1~8

Count: [0, 1, 2, 2, 1, 0, 0, 0, 1]
        0  1  2  3  4  5  6  7  8

누적합: [0, 1, 3, 5, 6, 6, 6, 6, 7]

결과: [1, 2, 2, 3, 3, 4, 8]
```

| 시간 | 공간 | 안정성 |
|------|------|--------|
| O(n + k) | O(n + k) | 안정 |

k는 값의 범위. k가 n보다 훨씬 크면 비효율적입니다.

### 기수 정렬 (Radix Sort)

**자릿수별로 정렬**합니다. 각 자릿수는 계수 정렬 사용합니다.

```
[170, 45, 75, 90, 802, 24, 2, 66]

1의 자리: [170, 90, 802, 2, 24, 45, 75, 66]
10의 자리: [802, 2, 24, 45, 66, 170, 75, 90]
100의 자리: [2, 24, 45, 66, 75, 90, 170, 802]
```

| 시간 | 공간 | 안정성 |
|------|------|--------|
| O(d × (n + k)) | O(n + k) | 안정 |

d는 자릿수, k는 기수(보통 10). 문자열 정렬에도 활용됩니다.

## 정렬 알고리즘 비교표

| 알고리즘 | 최선 | 평균 | 최악 | 공간 | 안정 | 특징 |
|---------|------|------|------|------|------|------|
| 버블 | O(n) | O(n²) | O(n²) | O(1) | ✓ | 구현 간단, 비효율적 |
| 선택 | O(n²) | O(n²) | O(n²) | O(1) | ✗ | 교환 횟수 최소 |
| 삽입 | O(n) | O(n²) | O(n²) | O(1) | ✓ | 거의 정렬된 데이터에 효율적 |
| 병합 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✓ | 항상 보장, 외부 정렬 |
| 퀵 | O(n log n) | O(n log n) | O(n²) | O(log n) | ✗ | 평균 가장 빠름, 캐시 효율 |
| 힙 | O(n log n) | O(n log n) | O(n log n) | O(1) | ✗ | 항상 보장, 제자리 |
| 계수 | O(n+k) | O(n+k) | O(n+k) | O(n+k) | ✓ | 정수, 범위 제한 시 |
| 기수 | O(d(n+k)) | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✓ | 자릿수 기반 |

## 정렬 알고리즘 선택 가이드

| 상황 | 추천 알고리즘 |
|------|-------------|
| 소규모 데이터 (n < 50) | 삽입 정렬 |
| 거의 정렬된 데이터 | 삽입 정렬 |
| 평균적으로 빠른 정렬 | 퀵 정렬 |
| 최악 보장 필요 | 병합 정렬, 힙 정렬 |
| 메모리 제한 | 힙 정렬, 퀵 정렬 |
| 안정성 필요 | 병합 정렬 |
| 정수, 범위 제한 | 계수 정렬, 기수 정렬 |
| 외부 정렬 (디스크) | 병합 정렬 |
| 범용 라이브러리 | 팀소트 (삽입 + 병합) |

**실제 사용:**
- Python: Timsort (삽입 + 병합)
- Java: Dual-Pivot Quick Sort (원시 타입), Timsort (객체)
- C++: Introsort (퀵 + 힙 + 삽입)

## 면접 예상 질문

**Q. 퀵 정렬과 병합 정렬의 차이?**

퀵 정렬은 피벗 기준 분할 후 정렬, 평균 O(n log n)이지만 최악 O(n²)입니다. 제자리 정렬이고 캐시 효율이 좋아 실제로 가장 빠릅니다. 병합 정렬은 분할 후 병합하며 항상 O(n log n)을 보장하지만 O(n) 추가 공간이 필요합니다. 안정 정렬입니다.

**Q. 퀵 정렬이 O(n²)이 되는 경우?**

이미 정렬된 배열에서 첫 번째나 마지막 요소를 피벗으로 선택하면 분할이 극도로 불균형해집니다. 한쪽은 0개, 다른 쪽은 n-1개가 되어 n번 분할이 필요합니다. 랜덤 피벗이나 median-of-three로 해결합니다.

**Q. 안정 정렬이란?**

같은 값을 가진 요소들의 상대적 순서가 정렬 후에도 유지되는 정렬입니다. 버블, 삽입, 병합, 계수, 기수 정렬이 안정 정렬입니다. 복합 키로 정렬할 때 중요합니다.

**Q. 힙 정렬의 장단점?**

장점은 항상 O(n log n)을 보장하고 O(1) 추가 공간만 사용합니다. 단점은 캐시 효율이 낮아(배열 점프가 많음) 실제로 퀵 정렬보다 느립니다. 불안정 정렬입니다.

**Q. 계수 정렬은 언제 사용하나요?**

정수이고 값의 범위(k)가 n과 비슷하거나 작을 때 O(n+k)로 매우 빠릅니다. k가 n보다 훨씬 크면 비효율적입니다. 비교 기반이 아니라 O(n log n) 한계를 깰 수 있습니다.

**Q. 실제 라이브러리는 어떤 정렬을 사용하나요?**

대부분 하이브리드 알고리즘을 사용합니다. Python과 Java 객체는 Timsort(삽입+병합), C++은 Introsort(퀵+힙+삽입)를 사용합니다. 작은 배열은 삽입 정렬이 오버헤드가 적어 효율적입니다.
